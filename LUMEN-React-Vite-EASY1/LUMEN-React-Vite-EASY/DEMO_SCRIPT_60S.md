# LUMEN — 60-Second Demo Script (Focus-first edition)

Use **Watch 60-sec demo** or open `/?demo=1`. Eight timed beats, 60 seconds total.

## 0:00–0:06 — Problem
**Say:** “A learner has a goal, then drowns in tutorials. LUMEN removes the ‘what now?’ moment.”

**On screen:** the clean landing page and the LUMEN rule.

## 0:06–0:13 — Pick one goal
**Say:** “For the demo I pick ‘Speak confidently’. One tap — no signup, no course catalog.”

## 0:13–0:19 — Personal context
**Say:** “Complete beginner, fifteen minutes a day, video-first. The plan fits my real life.”

## 0:19–0:27 — Generate the roadmap
**Say:** “One click builds a personalized six-step plan. It runs offline, so the demo never dies on Wi-Fi.”

## 0:27–0:35 — Roadmap + progress
**Say:** “LUMEN lands straight on the plan: Done, Now, Next — plus four quiet metrics for progress, level, streak and confidence.”

## 0:35–0:42 — One action only
**Say:** “There is no dashboard to decode. This screen shows one step, one action, one button. Focus mode is not a setting — it is the product.”

## 0:42–0:51 — First win
**Say:** “Completing an action updates progress, XP, the daily quest, streak and confidence immediately.”

## 0:51–1:00 — Reward arcade
**Say:** “Three short games give a motivating reset. XP is capped once per game per day, so rewards stay meaningful.”

**Closing line:** “LUMEN keeps the next step obvious and the momentum fun.”

## After the demo
Click **Build my own path**, then **Reward arcade** and let a judge play one game.

## If a judge asks “where is the dashboard?”
> “We removed it. The learning screen is Focus mode: one action, one button, with the full plan and daily quest right below, so nothing is hidden but nothing competes for attention.”
