# START HERE — LUMEN (focus-first build)

1. Extract this ZIP.
2. Open the folder that contains `package.json` in VS Code.
3. In the terminal: `npm install`
4. Then: `npm run dev`
5. Open `http://localhost:5173`.

Windows: double-click `RUN-LUMEN.bat`.

## Judge flow (about 90 seconds)

1. Click **Watch 60-sec demo** — the full story plays automatically.
2. Click **Build my own path**, pick a goal, press **Generate my roadmap**.
3. You land on the focus screen: one step, one action, one button.
4. Finish the action — XP, quest, streak and confidence update.
5. Scroll down: full six-step plan, then **Reward arcade** on the right.
6. Play **Tap Sprint**, **Memory Match** or **Daily Spin** (once-per-day XP).

If you see `ENOENT package.json`, you opened the parent folder — open the one that directly contains `package.json`.
