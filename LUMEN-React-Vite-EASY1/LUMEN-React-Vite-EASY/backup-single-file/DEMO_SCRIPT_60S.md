# LUMEN — 60-Second Demo Script

Use this script with the in-app **Watch 60-sec demo** button. The app’s captions match the timings below. Keep your pointer still unless the script says to click; the demo changes screens automatically.

**Opening line options:**
- “Learning a new skill is easy to start and strangely hard to continue. LUMEN fixes the ‘what now?’ problem.”
- “We turn an overwhelming skill into one glowing next step.”

---

## 0:00–0:06 — Problem

**On screen:** Landing page highlights “The LUMEN rule.”

**Say:**
> “A learner arrives with a goal, then gets lost in endless tutorials. LUMEN starts by removing the confusion: one goal, one clear path.”

---

## 0:06–0:13 — Goal

**On screen:** “Speak confidently” is selected.

**Say:**
> “For this demo, I want to speak confidently. I tap one goal. No account, no course catalog, no setup.”

---

## 0:13–0:19 — Personal context

**On screen:** Complete beginner, 15 minutes per day, watch-first.

**Say:**
> “I tell LUMEN where I’m starting, how much time I actually have, and how I like to learn. That means the roadmap fits my real life.”

---

## 0:19–0:27 — Generate roadmap

**On screen:** Roadmap is generated instantly.

**Say:**
> “The local Path Engine builds a personalized six-step constellation. It works offline, so the live demo never depends on an API key or internet.”

---

## 0:27–0:36 — Guided path

**On screen:** Constellation and current star are highlighted.

**Say:**
> “Every step is visible, but only one is glowing. Done, Now and Next are obvious at a glance. I can open any star, so I’m never trapped by a lock screen.”

---

## 0:36–0:44 — One next action

**On screen:** “Your next move” card is highlighted.

**Say:**
> “This card answers the only question that matters right now: what exactly should I do next? It gives me one small action and a time estimate.”

---

## 0:44–0:52 — Take action

**On screen:** First milestone is completed; progress, XP and streak update.

**Say:**
> “I complete the first star. Progress lights up, XP appears, my streak begins, and the app immediately moves the recommended action forward.”

---

## 0:52–1:00 — Confidence / close

**On screen:** Progress panel and new next action are highlighted.

**Say:**
> “In sixty seconds, a vague goal became a personalized roadmap, a finished first step and a confident next action. That’s LUMEN: no overwhelm, no lost learners.”

**Strong closing line:**
> “The interface does not ask learners to figure out the path. It simply shows the next star.”

---

## Backup plan if live Wi-Fi fails

Nothing depends on Wi-Fi. Open `index.html` directly and run the same demo. If the timed demo feels too fast, press **Pause**, present one beat manually, then press **Skip beat** to continue.

## After the demo

Click **Build my own path** and ask a judge to choose a goal. This is a strong finish because it proves the prototype is functional, not a recorded walkthrough.
